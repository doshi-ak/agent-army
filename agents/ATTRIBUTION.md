# Attribution

This repository is an **aggregation** — it contains agent definitions authored by
others, redistributed unmodified and organized into a deduplicated roster. It adds
no new agent prompts of its own; the value it adds is the cross-reference, dedup,
and organization.

## Upstream sources

| Source | Agents contributed | License |
|---|---|---|
| [VoltAgent/awesome-claude-code-subagents](https://github.com/VoltAgent/awesome-claude-code-subagents) | 154 ingested | MIT |
| [wshobson/agents](https://github.com/wshobson/agents) | 134 ingested (unique) | MIT |

Both projects are MIT-licensed. Each agent file here is copied **verbatim** from one
of the two repos above; per-file provenance (which repo each surviving agent came
from, and which won any size tie-break) is recorded in [`manifest.json`](./manifest.json)
and [`MERGES.md`](./MERGES.md).

If you use or fork this, please credit both upstream projects. For the authoritative,
maintained versions of any individual agent, go to its source repo — this snapshot
was assembled on 2026-07-10 and will drift as the upstreams evolve.
